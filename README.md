# Satyam Garg — Portfolio v2

A static, responsive developer portfolio built with vanilla HTML, CSS and JavaScript.

## Included

- Responsive navigation + mobile menu
- Scroll progress indicator
- Active section navigation
- Reveal animations with reduced-motion support
- Project filtering
- Animated portfolio stats
- SEO/Open Graph metadata
- GitHub, LinkedIn, LeetCode and project links
- No framework or build step required

## Run locally

Open `index.html` directly, or use any static server.
